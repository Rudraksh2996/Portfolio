# Rudraksh Sharma - Portfolio

A modern, interactive 3D developer portfolio built to showcase projects, skills, and certifications. 

## 🚀 Features
- **3D Interactive Hero**: A hand-drawn aesthetic 3D cube built with Framer Motion, fully interactive (drag to rotate) and responsive to scroll (explodes/scatters on scroll).
- **Interactive Cursor Pet**: A custom Oneko cat component that playfully follows your cursor and rests on the 3D cube when idle.
- **Modern UI Components**: Utilizes Kokonut UI (Bento Grid styling) for project and certification cards with smooth hover physics.
- **Fully Accessible**: High-contrast ratios globally (WCAG AA compliant).
- **Responsive Design**: Polished for both desktop and mobile viewing.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS v4, shadcn/ui, Kokonut UI
- **Animations**: Framer Motion
- **Icons**: Lucide React, React Icons
- **Language**: TypeScript

## 💻 Running Locally

1. Clone the repository:
```bash
git clone https://github.com/Rudraksh2996/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
