## Features
- Interactive 3D cube in the hero section — drag to rotate, with idle auto-rotation and a scroll-triggered scatter/burst animation
- Cursor-following cat that perches on the settled cube once you scroll past the hero
- Hand-drawn/sketch-style illustration aesthetic throughout
- Fully responsive layout across mobile, tablet, and desktop
- Sections for About, Certifications, Projects, Tech Stack, and Contact
- Smooth scroll-based animations powered by Framer Motion

## Tech Stack
- Framework: [Next.js](https://nextjs.org/) 14+ (App Router), TypeScript
- Styling: [Tailwind CSS](https://tailwindcss.com/), [shadcn/ui](https://ui.shadcn.com/)
- Animation: [Framer Motion](https://www.framer.com/motion/)
- UI Components: [Kokonut UI](https://kokonutui.com/)
- Icons: [Lucide React](https://lucide.dev/)
- Deployment: [Vercel](https://vercel.com/)

## Getting Started
Clone the repository and install dependencies:
```bash
git clone https://github.com/Rudraksh2996/portfolio.git
cd portfolio
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

Build
```bash
npm run build
npm run start
```
